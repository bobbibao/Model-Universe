# MODEL UNIVERSE – Dữ liệu seed mô hình mecha

Tổng hợp từ `MODEL_UNIVERSE_Mecha_Catalog_Image_Tracking.xlsx` (tạo 10/10/2026), cập nhật 11/10/2026. Mỗi dòng = 1 phiên bản (màu/đóng gói) của 1 mẫu.

## Quy ước

- Ô trống = `null` khi seed. Dấu `|` trong dữ liệu gốc đã được thay bằng `/`.
- `id`: slug tự sinh, ổn định theo `brand + sku/tên + phiên bản`, dùng làm khóa chính.
- `sku`: mã hãng. Trống nghĩa là chưa xác minh (không tự gán mã). `retailer_sku`: SKU của nhà bán lẻ (vd Newtype), **không phải mã hãng**.
- `image_status`: `verified` = URL ảnh khớp mẫu/phiên bản; `reference` = ảnh cùng mẫu nhưng chưa chắc đúng phiên bản; `placeholder` = ảnh giữ chỗ (placehold.co) cho dòng chưa tìm được ảnh thật, cần thay sau.
- `verification`: giữ nguyên trạng thái xác minh trong file gốc.
- Ảnh chỉ là URL hotlink từ nhà bán lẻ (nhiều URL `encrypted-tbn0.gstatic.com` là thumbnail Google, có thể hết hạn). Nên tải về storage của bạn trước khi dùng production.

## Seeding (2026-10-11)

- Seed source of truth: `src/core/server/database/client/seeders/data/model-universe-catalog.json`. The tables below are
  generated from it; change the JSON first, then the tables.
- A fresh `yarn seed-dev` / `yarn seed-ci` creates every row as a product. On an existing database run
  `yarn catalog:import`: it applies the migrations (table `product_source`) and adds the rows not imported yet, in one
  transaction; rows already imported are skipped, so staff edits survive a re-run.
- Mapping (`seeders/ModelUniverseCatalog.ts`): shop SKU `MU-<ID>`; `sku` → `product.modelCode`; `Kit lắp ráp` →
  category `mecha-model-kits` (unassembled), every figure type → `alloy-figures` (assembled); `N/A` scale → empty;
  stock is deterministic (limited/event editions 1–3, others 2–12); cost price = 60% of the list price. Provenance
  (`image_status`, `verification`, retailer SKU, sources, `price_source`, notes) is stored in `product_source` and
  returned only by the admin product API.
- New columns `price_vnd` / `price_source`: estimated list price in whole VND. Vietnamese retailer prices are used as
  is; foreign listings are converted with the seed convention USD × 25,000 (CAD × 0.72, AUD × 0.65, GBP × 1.30 to USD
  first), rounded to 10,000. Confirm prices before a real sale.
- New column `image_source_url`: the retailer page each researched image was taken from.
