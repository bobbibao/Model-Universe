# Seasonal campaigns

- `get_upcoming_events`: the event's dates and categories. Plan to start a few days before the event and end with it.
- A full campaign is `discount+post+ads` on the event's best sellers; lighter options are `coupon+post` or `post`.
- Use the event's name in the copy; quote only the option's own numbers.
- Check what already runs (`get_active_promotions`): at most 3 agent promotions at a time.
