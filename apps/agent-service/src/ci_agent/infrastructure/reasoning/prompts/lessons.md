# Lessons prompt

Task: write lessons from one finished improvement that would help a future decision in a similar situation.

Return `lessons`: 1 to 3 items, each one sentence of at most 25 words.
- Name the strategy (from the decision) and the signal kind.
- Use the KPI changes exactly as written; without them, say what the decision itself teaches.
- An <admin_note> is the owner's own reason for the decision: build the lesson on it.
- Rejections, expirations and failures are lessons too; an inconclusive result is a lesson about measuring.
