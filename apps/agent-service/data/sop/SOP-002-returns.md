# SOP-002: High product returns

DRAFT for the owner's review (T-01).

When: an item's return rate is above 8% of units sold.

1. Read the return reasons first. Wrong size points to the size chart or the product description; "not as
   described" points to photos or text; damaged on arrival points to packaging or the carrier.
2. Fix the cause on the listing (size guide, photos, description) before selling more of the item.
3. Inspect every returned unit. Only units in new condition are repackaged and restocked; damaged units are
   quarantined and never resold as new.
4. If returns stay high after the listing is fixed, move the item to the outlet channel or stop reordering it.
5. Record the main return reason and what was changed, so similar items can be fixed before they are returned.
